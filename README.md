# UNILAG Aggregate Calculator — Next.js

A Next.js 14 (App Router) app for UNILAG aspirants to calculate their admission aggregate and explore 5-year cutoff history across faculties.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Stack

- Next.js 14 (App Router)
- React 18
- Tailwind CSS 3
- Lucide React icons
- TypeScript

## Structure

- `app/` — routes (`/`, `/cutoffs`)
- `components/` — Calculator, CutoffList, FormulaInfo, Navbar, Footer
- `lib/unilag-data.ts` — grade points, 5-year cutoffs, calculator function
- `public/logo.png` — brand mark
